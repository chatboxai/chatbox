## Schnellstart

### Für Endbenutzer
1. Laden Sie das passende Installationsprogramm für Ihre Plattform von der [Releases-Seite](https://github.com/chatboxai/chatbox/releases) herunter
2. Installieren und starten Sie Chatbox
3. Konfigurieren Sie Ihren KI-Anbieter (OpenAI, Claude usw.) in den Einstellungen
4. Beginnen Sie zu chatten!

## Funktionen

### 🤖 KI-Modell-Unterstützung
-   **Unterstützung für mehrere LLM-Anbieter**  
    :gear: Nahtlose Integration mit einer Vielzahl modernster Sprachmodelle:
    -   OpenAI (ChatGPT)
    -   Azure OpenAI
    -   Claude
    -   Google Gemini Pro

-   **Bildgenerierung mit Dall-E-3**  
    :art: Erstellen Sie die Bilder Ihrer Vorstellung mit Dall-E-3.

-   **Installationspakete ohne Deployment**  
    :package: Schneller Einstieg mit herunterladbaren Installationspaketen. Keine komplexe Einrichtung nötig!

-   **Ergonomische Benutzeroberfläche und Dunkles Theme**  
    :new_moon: Eine benutzerfreundliche Oberfläche mit Nachtmodus-Option zur Reduzierung der Augenbelastung bei längerer Nutzung.

-   **Tastenkürzel**  
    :keyboard: Bleiben Sie produktiv mit Tastenkürzeln, die Ihren Workflow beschleunigen.

-   **Streaming-Antworten**  
    :arrow_forward: Schnelle Antworten auf Ihre Interaktionen mit sofortigen, progressiven Antworten.

### 📄 Inhalt und Formatierung
-   **Markdown, Latex und Code-Hervorhebung**

## Warum habe ich Chatbox entwickelt?

Ich habe Chatbox ursprünglich entwickelt, weil ich einige Prompts debuggte und ein einfaches und benutzerfreundliches Tool für Prompt- und API-Debugging brauchte. Ich dachte, es könnte mehr Menschen geben, die ein solches Tool benötigen, also habe ich es als Open Source veröffentlicht.

Anfangs wusste ich nicht, dass es so beliebt werden würde. Ich habe auf das Feedback der Open-Source-Community gehört und es weiterentwickelt und verbessert. Jetzt ist es zu einer sehr nützlichen KI-Desktop-Anwendung geworden. Es gibt viele Nutzer, die Chatbox lieben, und sie verwenden es nicht nur zum Entwickeln und Debuggen von Prompts, sondern auch für alltägliche Chats und sogar für interessantere Dinge, wie gut gestaltete Prompts zu verwenden, damit KI verschiedene professionelle Rollen spielt und sie bei der täglichen Arbeit unterstützt...

- Geben Sie detaillierte Informationen an, einschließlich Schritte zur Reproduktion, erwartetem Verhalten und Screenshots, falls zutreffend

### 🔧 Pull Requests
1. Forken Sie das Repository und erstellen Sie Ihren Branch von `main`

## Entwicklung

### Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Folgendes installiert ist:

- **Node.js** (v20.x – v22.x) - [Hier herunterladen](https://nodejs.org/)
- **pnpm** (v10.x oder höher) - Installieren via `corepack enable && corepack prepare pnpm@latest --activate`
- **Git** - [Hier herunterladen](https://git-scm.com/)

### Schnelle Einrichtung

1. **Repository klonen**
   ```bash
   git clone https://github.com/chatboxai/chatbox.git
   cd chatbox
   ```

2. **Abhängigkeiten installieren**
   ```bash
   pnpm install
   ```

3. **Entwicklungsserver starten**
   ```bash
   pnpm run dev
   ```
   Die Anwendung startet im Entwicklungsmodus mit aktiviertem Hot-Reload.

### Build-Befehle

| Befehl | Beschreibung |
|---------|-------------|
| `pnpm run dev` | Entwicklungsserver mit Hot-Reload starten |
| `pnpm run package` | Für aktuelle Plattform bauen und paketieren |
| `pnpm run package:all` | Für alle Plattformen bauen und paketieren |
| `pnpm run build` | Für Produktion bauen ohne Paketierung |
| `pnpm run lint` | Biome zur Code-Qualitätsprüfung ausführen |
| `pnpm run test` | Vitest-Testsuite ausführen |

### Projektstruktur

```
chatbox/
├── src/
│   ├── main/               # Electron-Hauptprozess
│   ├── renderer/           # React-Renderer (UI)
│   ├── preload/            # Electron-Preload-Skripte
│   └── shared/             # Gemeinsame Utilities
├── doc/                    # Dokumentation und Assets
├── resources/              # App-Ressourcen und Icons
├── team-sharing/           # Team-Kollaborationsfunktionen
└── package.json            # Projektkonfiguration
```

### Entwicklungstipps

- Verwenden Sie `pnpm run lint` vor dem Commit, um die Code-Qualität sicherzustellen
- Folgen Sie dem bestehenden Code-Stil und den Mustern
- Testen Sie Ihre Änderungen in hellen und dunklen Themes
- Stellen Sie plattformübergreifende Kompatibilität bei UI-Änderungen sicher

### Fehlerbehebung

**Problem**: `pnpm install` schlägt fehl
- **Lösung**: Stellen Sie sicher, dass Sie pnpm (nicht npm oder yarn) verwenden und die Node.js-Version im erforderlichen Bereich liegt. Führen Sie `corepack enable` aus, wenn pnpm nicht gefunden wird.

**Problem**: Build schlägt unter Windows fehl
- **Lösung**: Führen Sie `pnpm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"` aus, wenn Sie Git Bash verwenden

**Problem**: Änderungen werden in der Entwicklung nicht angezeigt
- **Lösung**: Stoppen Sie den Dev-Server, löschen Sie `node_modules/.vite` und starten Sie neu
