## Características

## ¿Por qué creé Chatbox?

Desarrollé Chatbox inicialmente porque estaba depurando algunos prompts y necesitaba una herramienta sencilla y fácil de usar para depurar prompts y APIs. Pensé que podría haber más personas que necesitaran una herramienta así, así que lo publiqué como código abierto.

Al principio, no sabía que sería tan popular. Escuché los comentarios de la comunidad de código abierto y continué desarrollándolo y mejorándolo. Ahora se ha convertido en una aplicación de escritorio de IA muy útil. Hay muchos usuarios que aman Chatbox, y no solo lo usan para desarrollar y depurar prompts, sino también para chatear a diario e incluso para hacer cosas más interesantes, como usar prompts bien diseñados para que la IA desempeñe diversos roles profesionales y les ayude en el trabajo cotidiano...

## Cómo contribuir

¡Damos la bienvenida a las contribuciones de la comunidad! Así puedes ayudar a mejorar Chatbox:

### 🐛 Informar de problemas
- Usa [GitHub Issues](https://github.com/chatboxai/chatbox/issues) para informar de errores o solicitar funciones
- Antes de crear un nuevo issue, busca en los existentes para evitar duplicados
- Proporciona información detallada, incluidos los pasos para reproducir el problema, el comportamiento esperado y capturas de pantalla si procede

### 🔧 Pull requests
1. Haz fork del repositorio y crea tu rama desde `main`
2. Realiza tus cambios y asegúrate de que el código sigue nuestros estándares
3. Prueba tus cambios a fondo
4. Actualiza la documentación si es necesario
5. Envía un pull request con una descripción clara de los cambios

- Mejora el README, la documentación de la API o las guías de usuario

### 🌟 Otras formas de contribuir
- Dale una estrella al repositorio para mostrar tu apoyo

## Desarrollo

### Requisitos previos

Antes de empezar, asegúrate de tener instalado lo siguiente:

- **Node.js** (v20.x – v22.x) - [Descargar aquí](https://nodejs.org/)
- **pnpm** (v10.x o posterior) - Instalar con `corepack enable && corepack prepare pnpm@latest --activate`
- **Git** - [Descargar aquí](https://git-scm.com/)

### Configuración rápida

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/chatboxai/chatbox.git
   cd chatbox
   ```

2. **Instala las dependencias**
   ```bash
   pnpm install
   ```

3. **Inicia el servidor de desarrollo**
   ```bash
   pnpm run dev
   ```
   La aplicación se iniciará en modo de desarrollo con recarga en caliente habilitada.

### Comandos de compilación

| Comando | Descripción |
|---------|-------------|
| `pnpm run dev` | Inicia el servidor de desarrollo con recarga en caliente |
| `pnpm run package` | Compila y empaqueta para la plataforma actual |
| `pnpm run package:all` | Compila y empaqueta para todas las plataformas |
| `pnpm run build` | Compila para producción sin empaquetar |
| `pnpm run lint` | Ejecuta Biome para comprobar la calidad del código |
| `pnpm run test` | Ejecuta la suite de pruebas de Vitest |

### Estructura del proyecto

```
chatbox/
├── src/
│   ├── main/               # Proceso principal de Electron
│   ├── renderer/           # Renderer de React (UI)
│   ├── preload/            # Scripts preload de Electron
│   └── shared/             # Utilidades compartidas
├── doc/                    # Documentación y recursos
├── resources/              # Recursos e iconos de la app
├── team-sharing/           # Funciones de colaboración en equipo
└── package.json            # Configuración del proyecto
```

### Consejos de desarrollo

- Usa `pnpm run lint` antes de hacer commit para garantizar la calidad del código
- Sigue el estilo de código y los patrones existentes
- Prueba tus cambios en los temas claro y oscuro
- Asegura la compatibilidad multiplataforma al modificar la interfaz

### Solución de problemas

**Problema**: `pnpm install` falla
- **Solución**: Asegúrate de usar pnpm (no npm ni yarn) y de que la versión de Node.js esté dentro del rango requerido. Ejecuta `corepack enable` si no se encuentra pnpm.

**Problema**: La compilación falla en Windows
- **Solución**: Ejecuta `pnpm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"` si usas Git Bash

**Problema**: Los cambios no se reflejan en desarrollo
- **Solución**: Detén el servidor de desarrollo, elimina `node_modules/.vite` y reinicia
