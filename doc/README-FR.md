## Fonctionnalités

### 🤖 Prise en charge des modèles d'IA
-   **Prise en charge de plusieurs fournisseurs de LLM**  
    :gear: Intégration transparente avec une variété de modèles de langage de pointe :
    -   OpenAI (ChatGPT)
    -   Azure OpenAI
    -   Claude
    -   Google Gemini Pro
    -   Ollama (permet d'accéder à des modèles locaux comme llama2, Mistral, Mixtral, codellama, vicuna, yi et solar)

-   **Génération d'images avec Dall-E-3**

    :speech_balloon: Fonctionnalités avancées de prompting pour affiner et cibler vos requêtes afin d'obtenir de meilleures réponses.

-   **Paquets d'installation sans déploiement**  
    :package: Démarrez rapidement avec des paquets d'installation téléchargeables. Aucune configuration complexe nécessaire !

-   **Interface ergonomique et thème sombre**  
    :new_moon: Une interface conviviale avec un mode nuit pour réduire la fatigue oculaire lors d'une utilisation prolongée.

-   **Raccourcis clavier**  
    :keyboard: Restez productif grâce à des raccourcis qui accélèrent votre flux de travail.

-   **Réponses en streaming**  
    :arrow_forward: Fournissez des réponses rapides à vos interactions avec des réponses immédiates et progressives.

-   **Markdown, Latex et coloration syntaxique**

## Pourquoi j'ai créé Chatbox ?

J'ai développé Chatbox initialement parce que je déboguais certains prompts et avais besoin d'un outil simple et facile à utiliser pour déboguer les prompts et les API. J'ai pensé qu'il pourrait y avoir d'autres personnes ayant besoin d'un tel outil, alors je l'ai publié en open source.

Au début, je ne savais pas que ce serait si populaire. J'ai écouté les retours de la communauté open source et j'ai continué à le développer et à l'améliorer. Aujourd'hui, c'est devenu une application de bureau IA très utile. De nombreux utilisateurs adorent Chatbox, et ils ne l'utilisent pas seulement pour développer et déboguer des prompts, mais aussi pour discuter au quotidien, et même pour faire des choses plus intéressantes, comme utiliser des prompts bien conçus pour faire jouer à l'IA divers rôles professionnels afin de les aider dans leur travail quotidien...

## Comment contribuer

Nous accueillons les contributions de la communauté ! Voici comment vous pouvez aider à améliorer Chatbox :

### 🐛 Signaler des problèmes
- Utilisez [GitHub Issues](https://github.com/chatboxai/chatbox/issues) pour signaler des bugs ou demander des fonctionnalités
- Avant de créer un nouveau ticket, veuillez rechercher les tickets existants pour éviter les doublons

2. Apportez vos modifications et assurez-vous que le code respecte nos standards

## Développement

### Prérequis

Avant de commencer, assurez-vous d'avoir installé les éléments suivants :

- **Node.js** (v20.x – v22.x) - [Télécharger ici](https://nodejs.org/)
- **pnpm** (v10.x ou ultérieur) - Installer via `corepack enable && corepack prepare pnpm@latest --activate`
- **Git** - [Télécharger ici](https://git-scm.com/)

### Configuration rapide

1. **Clonez le dépôt**
   ```bash
   git clone https://github.com/chatboxai/chatbox.git
   cd chatbox
   ```

2. **Installez les dépendances**
   ```bash
   pnpm install
   ```

3. **Démarrez le serveur de développement**
   ```bash
   pnpm run dev
   ```
   L'application démarrera en mode développement avec le rechargement à chaud activé.

### Commandes de build

| Commande | Description |
|---------|-------------|
| `pnpm run dev` | Démarre le serveur de développement avec rechargement à chaud |
| `pnpm run package` | Compile et empaquette pour la plateforme actuelle |
| `pnpm run package:all` | Compile et empaquette pour toutes les plateformes |
| `pnpm run build` | Compile pour la production sans empaquetage |
| `pnpm run lint` | Exécute Biome pour vérifier la qualité du code |
| `pnpm run test` | Exécute la suite de tests Vitest |

### Structure du projet

```
chatbox/
├── src/
│   ├── main/               # Processus principal Electron
│   ├── renderer/           # Renderer React (UI)
│   ├── preload/            # Scripts preload Electron
│   └── shared/             # Utilitaires partagés
├── doc/                    # Documentation et ressources
├── resources/              # Ressources et icônes de l'app
├── team-sharing/           # Fonctionnalités de collaboration en équipe
└── package.json            # Configuration du projet
```

### Conseils de développement

- Utilisez `pnpm run lint` avant de committer pour garantir la qualité du code
- Suivez le style de code et les modèles existants
- Testez vos modifications sur les thèmes clair et sombre
- Assurez la compatibilité multiplateforme lors des modifications de l'interface

### Dépannage

**Problème** : `pnpm install` échoue
- **Solution** : Assurez-vous d'utiliser pnpm (et non npm ou yarn) et que la version de Node.js est dans la plage requise. Exécutez `corepack enable` si pnpm n'est pas trouvé.

**Problème** : Le build échoue sur Windows
- **Solution** : Exécutez `pnpm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"` si vous utilisez Git Bash

**Problème** : Les modifications ne se reflètent pas en développement
- **Solution** : Arrêtez le serveur de développement, supprimez `node_modules/.vite` et redémarrez
