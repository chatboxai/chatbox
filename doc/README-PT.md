## Por que criei o Chatbox?

Desenvolvi o Chatbox inicialmente porque estava depurando alguns prompts e senti a necessidade de uma ferramenta simples e fácil de usar para depuração de prompts e APIs. Achei que poderia haver mais pessoas que precisassem de uma ferramenta assim, então o tornei open-source.

No início, não sabia que seria tão popular. Ouço o feedback da comunidade open-source e continuo desenvolvendo e melhorando. Agora, tornou-se um aplicativo de desktop de IA muito útil. Há muitos usuários que adoram o Chatbox, e eles não o usam apenas para desenvolver e depurar prompts, mas também para conversas do dia a dia, e até para fazer coisas mais interessantes, como usar prompts bem elaborados para fazer a IA assumir vários papéis profissionais e ajudá-los no trabalho cotidiano...

## Como Contribuir

Acolhemos contribuições da comunidade! Veja como você pode ajudar a tornar o Chatbox ainda melhor:

- Use [GitHub Issues](https://github.com/chatboxai/chatbox/issues) para reportar bugs ou solicitar recursos

## Desenvolvimento

### Pré-requisitos

Antes de começar, certifique-se de ter o seguinte instalado:

- **Node.js** (v20.x – v22.x) - [Download aqui](https://nodejs.org/)
- **pnpm** (v10.x ou posterior) - Instale via `corepack enable && corepack prepare pnpm@latest --activate`
- **Git** - [Download aqui](https://git-scm.com/)

### Configuração Rápida

1. **Clone o repositório**
   ```bash
   git clone https://github.com/chatboxai/chatbox.git
   cd chatbox
   ```

2. **Instale as dependências**
   ```bash
   pnpm install
   ```

3. **Inicie o servidor de desenvolvimento**
   ```bash
   pnpm run dev
   ```
   O aplicativo será iniciado em modo de desenvolvimento com hot-reload habilitado.

### Comandos de Build

| Comando | Descrição |
|---------|-------------|
| `pnpm run dev` | Inicia o servidor de desenvolvimento com hot-reload |
| `pnpm run package` | Compila e empacota para a plataforma atual |
| `pnpm run package:all` | Compila e empacota para todas as plataformas |
| `pnpm run build` | Compila para produção sem empacotamento |
| `pnpm run lint` | Executa o Biome para verificar a qualidade do código |
| `pnpm run test` | Executa a suíte de testes Vitest |

### Estrutura do Projeto

```
chatbox/
├── src/
│   ├── main/               # Processo principal do Electron
│   ├── renderer/           # Renderer React (UI)
│   ├── preload/            # Scripts preload do Electron
│   └── shared/             # Utilitários compartilhados
├── doc/                    # Documentação e assets
├── resources/              # Recursos e ícones do app
├── team-sharing/           # Recursos de colaboração em equipe
└── package.json            # Configuração do projeto
```

### Dicas de Desenvolvimento

- Use `pnpm run lint` antes de fazer commit para garantir a qualidade do código
- Siga o estilo de código e os padrões existentes
- Teste suas alterações nos temas claro e escuro
- Garanta compatibilidade multiplataforma ao fazer alterações na UI

### Solução de Problemas

**Problema**: `pnpm install` falha
- **Solução**: Certifique-se de estar usando pnpm (não npm ou yarn) e que a versão do Node.js está dentro da faixa exigida. Execute `corepack enable` se o pnpm não for encontrado.

**Problema**: Build falha no Windows
- **Solução**: Execute `pnpm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"` se estiver usando Git Bash

**Problema**: Alterações não refletem no desenvolvimento
- **Solução**: Pare o servidor de desenvolvimento, exclua `node_modules/.vite` e reinicie
