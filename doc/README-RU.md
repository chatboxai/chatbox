## Почему я создал Chatbox?

Изначально я разработал Chatbox, потому что отлаживал некоторые промпты и мне нужен был простой и удобный инструмент для отладки промптов и API. Я подумал, что такой инструмент может понадобиться и другим людям, поэтому открыл его исходный код.

Сначала я не знал, что он станет настолько популярным. Я прислушивался к отзывам open-source-сообщества и продолжал разрабатывать и улучшать его. Теперь это стало очень полезным AI desktop-приложением. Много пользователей любят Chatbox, и они используют его не только для разработки и отладки промптов, но и для повседневного общения, а также для более интересных вещей — например, с помощью хорошо продуманных промптов заставляют ИИ играть различные профессиональные роли и помогать им в повседневной работе...

## Разработка

### Требования

Перед началом убедитесь, что у вас установлено следующее:

- **Node.js** (v20.x – v22.x) - [Скачать здесь](https://nodejs.org/)
- **pnpm** (v10.x или новее) - Установите через `corepack enable && corepack prepare pnpm@latest --activate`
- **Git** - [Скачать здесь](https://git-scm.com/)

### Быстрая настройка

1. **Клонируйте репозиторий**
   ```bash
   git clone https://github.com/chatboxai/chatbox.git
   cd chatbox
   ```

2. **Установите зависимости**
   ```bash
   pnpm install
   ```

3. **Запустите сервер разработки**
   ```bash
   pnpm run dev
   ```
   Приложение запустится в режиме разработки с включённым hot-reload.

### Команды сборки

| Команда | Описание |
|---------|-------------|
| `pnpm run dev` | Запуск сервера разработки с hot-reload |
| `pnpm run package` | Сборка и упаковка для текущей платформы |
| `pnpm run package:all` | Сборка и упаковка для всех платформ |
| `pnpm run build` | Сборка для production без упаковки |
| `pnpm run lint` | Запуск Biome для проверки качества кода |
| `pnpm run test` | Запуск тестового набора Vitest |

### Структура проекта

```
chatbox/
├── src/
│   ├── main/               # Основной процесс Electron
│   ├── renderer/           # React renderer (UI)
│   ├── preload/            # Preload-скрипты Electron
│   └── shared/             # Общие утилиты
├── doc/                    # Документация и ресурсы
├── resources/              # Ресурсы и иконки приложения
├── team-sharing/           # Функции командной работы
└── package.json            # Конфигурация проекта
```

### Советы по разработке

- Используйте `pnpm run lint` перед коммитом для обеспечения качества кода
- Следуйте существующему стилю кода и паттернам
- Тестируйте изменения в светлой и тёмной темах
- Обеспечивайте кроссплатформенную совместимость при изменении UI

### Устранение неполадок

**Проблема**: `pnpm install` завершается с ошибкой
- **Решение**: Убедитесь, что вы используете pnpm (не npm или yarn) и версия Node.js находится в требуемом диапазоне. Выполните `corepack enable`, если pnpm не найден.

**Проблема**: Сборка завершается с ошибкой на Windows
- **Решение**: Выполните `pnpm config set script-shell "C:\\Program Files\\git\\bin\\bash.exe"`, если используете Git Bash

**Проблема**: Изменения не отображаются в режиме разработки
- **Решение**: Остановите dev-сервер, удалите `node_modules/.vite` и перезапустите
