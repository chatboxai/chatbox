# 桌面端云同步

> Last updated: 2026-11

在桌面端的 **数据与备份 → 同步** 中启用同步，选择 WebDAV 或百度网盘，以及参与同步的对话、设置、Copilot 和模型供应商凭据。同步默认关闭。启用后可立即同步，也可选择定时或关窗同步。应用启动后会检查一次云端数据。Web 和移动端仍使用各自的手动备份入口。

WebDAV 使用用户提供的服务地址和可选账号，先通过 `PROPFIND` 验证访问权限。更新现有文件时要求强 ETag。百度网盘使用用户自己的百度网盘开放平台应用，注册回调地址 `http://127.0.0.1:1456/auth/callback`，并在每台设备填写 AppKey 和 SecretKey。为兼容已有 ChatAny 同步数据，保留 `ChatAny-Sync-v1.json`、WebDAV 的 `ChatAny/` 目录和百度网盘的 `/apps/ChatAny` 目录。

## 数据与安全边界

- 同步复用 [V3 备份](./data-backup.md)，以云端 revision 和本地内容指纹决定是否上传或从云端恢复。初次连接已有云端数据时采用云端快照。远端 revision 变化后按所选类别替换本地数据，显式变更同步类别时会上传新的本地快照。
- WebDAV 使用条件写入处理并发覆盖。百度网盘在上传前比较文件标识，最终写入仍受百度网盘接口的并发语义约束。发现冲突时重新读取一次云端快照。
- 恢复前检查云端指纹、备份格式和类别，再取得受影响类别的本地内存快照。导入失败时尝试用快照恢复。持久恢复点和整包事务仍未实现，异常退出可能中断恢复。同步归档上限为 128 MiB，手动备份沿用自身容量限制。
- Electron 主进程管理服务端通信、OAuth 和加解密。WebDAV 密码、百度应用凭据、OAuth token 和同步加密 Token 保存在当前桌面配置的系统加密存储中。启用端到端加密后，V3 归档用 AES-256-GCM 加密，Token 通过 PBKDF2-HMAC-SHA-256 派生密钥。Token 丢失将无法恢复加密归档。
- 云端文件包含 revision、设备 ID 和类别等同步元数据。模型供应商凭据只有在勾选后才随备份上传。关闭端到端加密时，存储服务可读取归档。WebDAV 支持 HTTP 以兼容本地服务器，跨网络访问应使用 HTTPS。

正常的手动备份仍由原入口处理。桌面同步通过有类型的 preload 接口接入，主进程仅受理应用主窗口主框架发起的同步请求。
